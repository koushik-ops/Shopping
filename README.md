Mysql-shopping

A web-based e-commerce platform built with Node.js and MySQL. This application features a shopping cart, product management, and a secure database connection.

Getting StartedFollow these steps to set up the project locally on your machine:
Prerequisites
-Node.js installed
-MySQL Server (e.g., XAMPP, WAMP, or standalone MySQL)
-A code editor like VS Code

Project Structure
-index.js: Main entry point for the server.
-dbconnection.js: Configuration for MySQL database connection.
-dbshop.js & dbtableshop.js: Database logic for handling shop data and table structures.
-package.json: Project metadata and dependencies. 

Features
-Product Browsing: View items available in the shop.
-Shopping Cart: Add, update, and remove products.
-MySQL Integration: Persistent storage for users, products, and orders.
