# 🛒 Shopping Management System

A web-based **Shopping Management System** built using **Node.js**, **Express.js**, and **MySQL** to manage products, customers, orders, and inventory efficiently.

## 🚀 Features

### 📦 Product Management

* Add new products
* View product details
* Update product information
* Delete products from inventory

### 👤 Customer Management

* Register new customers
* View customer information
* Manage customer records

### 🛍️ Order Management

* Create new orders
* View order history
* Manage order details

### 📊 Inventory Management

* Track available stock
* Update product quantities
* Monitor inventory status

### 🗄️ Database Operations

* MySQL database connectivity
* CRUD operations
* Efficient data storage and retrieval

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/koushik-ops/Shopping.git
```

### Move into the project directory

```bash
cd Shopping
```

### Install dependencies

```bash
npm install
```

### Configure the database

Create a MySQL database and update the database connection settings in the project configuration file.

### Start the server

```bash
npm start
```

or

```bash
node index.js
```

---

## ▶️ Running the Application

After starting the server, open your browser and visit:

```text
http://localhost:3000
```
